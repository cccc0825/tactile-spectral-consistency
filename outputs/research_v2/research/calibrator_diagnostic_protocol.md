# Post-review calibration-specific diagnostic protocol

This is a new local protocol recorded after all physical-data results and all three round-2 reports are frozen. It is explicitly exploratory simulation/implementation evidence, not a new real-data hypothesis or external preregistration. No physical-data output, model, selection, exclusion, or main contrast may change.

## Scope and fixed settings

Use the unchanged `experiments/response_calibration.py` (SHA-256 b2096e13e7978dc8e2b4d5280488f924f813e57b1f7701b02ead2687241c668a), its 12 cosines and actual penalty 0.01. No nearly unpenalized replacement, sensitivity tuning, favorable seed selection or construction changes after inspecting outcomes. Two CPU threads, 300 active seconds maximum. Preserve failed attempts and all outputs.

A. Direct additive-model diagnostic. Use NumPy Generator seed 20270914, twelve classes, four scalar-offset repetitions, class log-spectra drawn once N(0,0.5^2) on 128 bins, and true response coefficients theta[0]=0.6, theta[1]=-0.3, all others zero. Generate normalized positive log spectra as logsumexp-normalized u_c+B_v theta+scalar offsets N(0,0.2^2). The scalar offsets are normalizing nuisances, not new independent samples. Test the declared Cluster settings (lo40,hi800,ref40,support20..1200; source30/40/50, held-out20/60) and Lima settings (lo5,hi100,ref35,support4..120; source30/35, held-out40). Use repetitions 0/1 at source speeds for fitting; all repetitions at held-out speeds for evaluation. Fit the actual calibration without target means/labels. This construction tests the exact additive approximation, not sampled physical signals. Record source contrast residual and response-error metrics, not an assertion that ridge fits exactly.

B. Finite sampled-signal diagnostic. Reuse the immutable two-band construction in `experiments/diagnostics/synthetic_signals_psd.npz`; the generating code and original results are already known and must remain unchanged. The stored ideal and 200 Hz fourth-order causal Butterworth observations were generated as 3 s signals at 6 kHz with central 1 s Welch 1024/512. This test adds the actual calibrator to that finite chain. Use its original source30/40/50 at repetitions0/1 and held-out20/60 at all four repetitions, all twelve templates. Apply Cluster settings above, temporal/spatial/corrected methods, common source-fold selection over C=1/10/100 and gamma multiplier=.25/1/4 divided by128. Refit calibration/scaler/SVM inside each held-source-speed CV fold. Select by mean fold macro recall, ties preferring smaller C then multiplier. Retain every candidate, final model, predicted label, selected configuration and response coefficient. All six source-selected models must be saved and hashed before any newly produced target prediction.

## Diagnostic metrics

For both A and B, compare the fitted response evaluated at the actual geometric temporal bin centers against the known response. For ideal observations the true log-power response is zero; for filtered B use log squared magnitude of the same discrete Butterworth filter evaluated with sosfreqz at those centers. For direct additive A use the declared true cosine response. Compare source double-centered response contrasts and report their RMS error. Also regress estimated-minus-true response on intercept and log temporal frequency using source grid values only, then apply that fixed affine gauge adjustment to source and held-out grids. Report source/held-out gauge-adjusted RMS errors and unadjusted errors separately. Gauge alignment uses known simulation truth only for evaluation; it must not alter feature correction or classifier predictions. Under B, the pointwise filter response is a reference approximation because finite-window spectral estimates need not factor exactly.

Report mean source contrast variance explained and target macro accuracy for B, plus per-template outcomes and descriptive within-template spectral dispersion if computed. Do not infer physical identification or a causal explanation of either real dataset from these results. Do not attach population p-values to deterministic templates or technical repetitions. The diagnostic can succeed, fail, or show a regularization/finite-estimation limit; all outcomes are publishable within this diagnostic scope.

## Completion and stop rules

A source/model seal precedes B target inference. Save code/protocol/input hashes, configuration, seed, run commands, logs, timing, full candidate scores, all model/prediction artifacts and machine-generated summary tables. Stop after this single construction and fixed matrix; do not redesign it based on results. A separate checker must verify the implementation, counts, gauge calculation and results before any new statement enters the paper. The diagnostic supplements the present finite-method interpretation and cannot promote the physical-data benefit claim.
